Tap Bible Release Notes

What's changed in each version

v0.4.1
Apr 2026
  • Polished dialog animations on iOS — entry and exit transitions now work correctly
  • Fixed back-handler registration so hardware/gesture back works in all screens
  • Migrated all dialogs and bottom sheets to a unified dialog framework
  • Fixed occasional incorrect initial scroll position on iOS when dark mode is active
v0.4.0
Mar 2026
  • Launched on the iOS App Store
  • Added translations for multiple languages
v0.3.0
Feb 2026
  • Animated splash screen on Android
  • Fixed back navigation in the book/chapter navigator
  • Search: close keyboard on submit, show "No Results" when empty, tidier history layout
  • Refreshed colour palette for better readability
v0.2.0
Jan 2026
  • Fixed TSK ThML parsing and commentary navigation for missing verses
  • Excluded duplicate eBible entries from the catalog
  • Language names now shown instead of language codes
  • More robust document downloads
  • Dark mode highlight and popup link colours improved
  • Various dialog animation and border colour fixes
v0.1.0
Dec 2025
  • Initial release on Google Play
  • Bible reading with multiple tabs and translations
  • Full-text search, bookmarks, and commentaries
  • Hundreds of languages via CrossWire and eBible catalogs
